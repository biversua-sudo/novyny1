# 📰 Новини — агрегатор новин

Свіжі новини з перевірених джерел в одному місці. Працює на ПК і на телефоні.
Сервер не потрібен: GitHub сам кожні 30 хвилин збирає новини і публікує сторінку. Безкоштовно.

## Що вміє
- Розділи: Світ, Україна, Бізнес, Фінтех, Мілтех, Інша думка
- Позначка **НОВЕ** — для новин, що з'явились після останнього візиту
- Прочитані новини стають блідими
- Таймер читання: скільки хвилин прочитано сьогодні з ліміту 60 хв
- Якщо стрічка якогось сайту не працює — новини цього сайту беруться через Google News
- Внизу сторінки видно, які джерела працюють

## Файли
| Файл | Що це |
|---|---|
| `sources.py` | **Список джерел.** Щоб додати чи прибрати джерело — редагуй тільки його |
| `fetch_news.py` | Скрипт, який збирає новини і складає сайт |
| `web/` | Вигляд програми (сторінка, іконки) |
| `.github/workflows/update.yml` | Розклад: каже GitHub запускати збір новин кожні 30 хв |

---

## 🚀 Запуск

1. **Створи репозиторій** на github.com → **New** → назва `novyny` → **Public** → **Create repository**.
2. **Завантаж файли:** на сторінці репозиторію натисни **"uploading an existing file"**, виділи все всередині папки `novyny` і перетягни у вікно → **Commit changes**.
   Перевір, що в репозиторії з'явилась папка `.github` (вона може бути прихована на комп'ютері, див. нижче).
3. **Увімкни сайт:** **Settings** → **Pages** → у полі **Source** обери **GitHub Actions**.
4. **Запусти перше оновлення:** вкладка **Actions** → зліва **"Оновити новини"** → кнопка **Run workflow** → **Run workflow**. Зачекай 1–2 хвилини, поки з'явиться зелена галочка.
5. **Відкрий програму:** `https://ТВІЙ-НІК.github.io/novyny/`
   (точне посилання є в **Settings → Pages**).

### Якщо папка `.github` не завантажилась
На сторінці репозиторію: **Add file → Create new file** → у назві файлу напиши
`.github/workflows/update.yml` → встав вміст цього файлу з архіву → **Commit changes**.

## 📱 Встановити як застосунок
- **Android (Chrome):** меню ⋮ → **"Додати на головний екран"** / **"Встановити застосунок"**
- **iPhone (Safari):** "Поділитися" → **"На початковий екран"**
- **ПК (Chrome / Edge):** значок встановлення праворуч в адресному рядку

## ⚠️ Важливо знати
- GitHub може запускати оновлення із запізненням на 10–20 хвилин — це нормально.
- Якщо 60 днів нічого не змінювати в репозиторії, GitHub призупинить автооновлення і надішле лист на пошту.
  Тоді: **Actions → "Оновити новини" → Enable workflow**. Або просто зміни будь-що в репозиторії раз на два місяці.

## ➕ Як додати нове джерело
Відкрий `sources.py` прямо на GitHub (значок олівця) і додай рядок у потрібний розділ:
```python
{"cat": "fintech", "name": "Назва сайту", "url": "https://site.com/feed/",
 "site": "site.com", "lang": "en"},
```
Якщо не знаєш адресу стрічки — постав `"url": None`, а в `"site"` впиши домен.
Після збереження сайт оновиться сам за 1–2 хвилини.
